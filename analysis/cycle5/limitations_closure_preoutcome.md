# Joint function pilot: limitations resolved before outcomes

The analysis is now specified as a descriptive test of deposited reporter output and relative growth, with a protected holdout within the same processed library. It cannot establish calibrated biological uncertainty, independent experimental replication or a practical impact threshold from the currently authenticated material. No new phenotype value or missingness indicator was inspected when this report was written.

## Two concrete design findings

For the symmetric two-trait additive square, take opposite endpoints with scores `(0,0)` and intermediates `(m,-m)` and `(-m,m)`, with `m > 0`. If all eight score coordinates can vary in the full Cartesian error box of radius `epsilon >= 0`, and endpoint thresholds are recomputed in every realization, the joint-only obstruction survives every realization if and only if `m > 2 epsilon`. Equality admits a path through a weak-threshold tie. An explicit proof and 45,928 exact finite checks support this elementary resolution statement. The finite checks do not replace the proof. No empirical value of epsilon has been established.

Target deduplication does not provide a second independent performance estimate in this design. Before missingness, the development arm has 22 prediction cases but 21 distinct targets. The only repeated target occurs in a group containing only that target. Averaging case losses within targets and then within groups therefore gives the same equally weighted group loss as the original method, including after missingness. Endpoint-specific labels remain separate. The reserved arm has 24 cases and 24 targets before phenotype exclusions.

## Coverage is a separate feasibility gate

A frozen metadata-only simulation evaluated 13 hypothetical missingness scenarios, with 10,000 draws each. Shared genotype identities were retained. Under an invented 5% probability of missing each required field independently, development and reserved evaluation coverage passed in 2.19% and 3.81% of draws. Those numbers describe fragility under that stipulated model. They are not estimates of actual missingness, biological power or the probability that the real pilot succeeds.

The result supports keeping every missing-target failure and assessing coverage only at the authorized stage. It does not justify changing the split, lowering the minimum, choosing better-covered corners or imputing missing values.

## Frozen sequence of decisions

1. Finish independent review of the supplemental diagnostic implementation and preserve the reviewed code hashes.
2. Freeze the original protocol together with its explicit amendment, computational inputs, source audit and review receipts.
3. Read only permitted development inputs, calculate all three predictors and seal their numerical values.
4. Open development outcomes. An author-mean discrepancy above the fixed tolerance stops scientific interpretation and requires a provenance diagnosis.
5. If the source gate passes, retain every primary result, baseline failure, group deletion, component comparison and sensitivity result. Freeze the development report.
6. Record whether the unchanged question warrants opening the reserved arm. Do not use reserved coverage or class balance to decide. If opened, repeat the same protected sequence and preserve every failure.
