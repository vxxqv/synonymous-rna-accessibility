# Successor decision

**Do not begin another phenotype analysis yet.** The best next step is one metadata-only paired-context gate. None of the reviewed routes currently satisfies all four requirements together: authenticated identical coding sequences, measured multi-step coverage, calibrated uncertainty and independent validation material.

| 2 | Predict observed joint path decisions beyond a multi-trait additive/thermodynamic null | [PDZ extensions2026](https://doi.org/10.1038/s41467-026-69673-w), with separately generated [homolog2026](https://doi.org/10.1038/s41467-026-71005-x) material | Held-out graph-decision calibration, not newly discovered allostery | Exact two-assay genotype intersections and complete four-genotype graphs; amino-acid method scope, not synonymous RNA validation |
| 3 | Test a scalar monotone global-epistasis explanation | [R&R2025](https://doi.org/10.1073/pnas.2509444122), with MAVE-NN2022/MoCHI2024 as precedents | A correctly scoped falsification/control, not a new rank method | Sufficient repeated backgrounds and a calibrated error model; challenge every rejection against a second additive latent trait |

The new Shanas source is publicly documented and has retrievable sample metadata: 100 FASTQ rows correspond to 50 source samples, not 100 independent replicates. Its cassette is inserted before the GFP stop, so a synonymous full-ORF interpretation cannot be assumed. The source already analyzes promoter dependence, sequence features and integrated contexts. This makes exact source matching and an original-analysis comparison the first decision, not an invitation to repeat its results. Mordstein's earlier sequence/variant-index gap remains unresolved; it was not retried without new evidence.

Modern models address different parts of the problem. A common monotone transformation preserves the existing fixed-field barrier, and additive antagonism can generate it. R&R is vulnerable to omitted latent traits; MoCHI already supports shared multi-trait nonlinear models; Lilace needs the underlying bin/control information and cannot recover absent cross-assay covariance. None creates independent validation from the two now-exposed Cambray arms.

Recommend route 1's source-only gate first. If strict synonymy or a distinct held-out question fails, stop that branch. Route 2 is the strongest concrete general-method benchmark only if the scope change is explicit. Preserve the current pilot's failed primary coverage/prediction and category B/D interpretation unchanged.

Detailed methods, source locators, criteria, stop rules and cost classes are in `review.md`. Retained primary sources are for local verification, not computational-release packaging. No new phenotype files, model fits, interventions or external writes were performed. Published paper examples/aggregates are exposed literature and must not be called untouched validation. Amass quota was reached; no more calls were made after the two logged rejected attempts.
