# Measured synonymous and native-exon route sources

## Charter

Goal: identify at most three primary sources with a concrete existing-data contract for measured, multi-step synonymous or native-exon splicing routes. Scope/object/subject: functional constraints on synonymous sequence change / bounded measured splicing landscapes / the FAS combinatorial and local libraries, with WT1 as a coding-contract counterexample. This is an exploratory eligibility audit, separately authored with inherited project context, not a blinded external review. Current baseline supplied by root is `53b8ec8390cf3b028c294058e4c0f7c2de8c6b79`.

Questions: Q1 authenticate intended coding consequences and design coverage; Q2 distinguish experimental preparations from sequencing/PCR labels; Q3 identify normalization and uncertainty limits; Q4 locate separate validation material and a distinct, falsifiable next question. No deposited phenotype or outcome-missingness table was opened. No model was fitted.

Knowledge depth is working for source eligibility, not exhaustive for all splicing landscapes. The prior SMN1, OpenSplice, Mordstein, Cambray and Shanas decisions were checked first. Cambray's exposed, failed arms and Shanas's failed complete-CDS gate were not reopened. Amass quota exhaustion and earlier Scite/Elicit access failures were respected. Consensus located primary papers; public primary XML, GEO metadata, an author repository and a native RefSeq record supplied the evidence.

### Source1: FAS2019, ranked first

**Qualified GO for a frozen72-genotype native-reference-protein subgraph contract.** It advances synonymous sequence analysis because actual native CDS annotation, rather than a cassette label, determines a multi-step same-protein subset. The complete3072 design spans80 conceptual translation-string classes; that number does not imply80 expressed proteins. A convenient8-vertex cube exists, but should not replace the full72 after outcomes. The whole source is not synonymous.

Exact graph factors are the existing codon states CTT-CTG-TTG at24/26, TTG-CTG-CTC at39/41, and three binary synonymous sites32,35,44. The resulting graph has72 vertices and204 undirected edges. These are translations and adjacency relations of the published design, not new sequence designs or an observed functional result.

**Measurement contract.** GEO lists `GSE111316_Processed_Data_File_01.xlsx`, whose documented fields include Sequence, Genotype.ID, Number.Mutations, nine ES values, nine estimated PSI values and mean/SD summaries. Author count paths are `002_Processing_sequencing_data/001_Phylogeny_library_in_HEK293/Count_Files/Phylogeny_HEK293_BR_Rep_{1..9}.3072.counts` and corresponding `TR_Rep_{1..3}` files. The pinned tree gives each blob identity without opening values. Raw files are unnecessary to decide this eligibility gate.

Let O[v,b] be output counts and I[v,t] technical-input counts. Inspected author code computes

`ES[v,b] = (O[v,b]/sum_u O[u,b]) / median_t(I[v,t]/sum_u I[u,t])`.

It aligns sequences using TR1 row names; silent imputation of absent sequences is not justified. The sums refer to source library files, not the selected72 subset. A future selective reader must preserve the deposited library normalization or obtain only the required global totals, rather than recomputing totals on72 rows. These9 ES columns are not independent conditional on every shared preprocessing quantity. The same input estimate is reused across outputs, and all genotypes within an output share a compositional total. Source plate/well transfections are documented; independent cloning batches, culture days, passage blocks and all technical covariances are not.

**Uncertainty eligibility.** Nine separately transfected output preparations permit empirical transfection-level variation of joint genotype vectors conditional on this library/input. Three input PCRs characterize technical input variability, not three biological cohorts. Counts can support a declared multinomial/Poisson sampling model, but this alone does not calibrate PCR amplification, RT efficiency, library-composition bias or systematic genotype-dependent recovery. No UMIs, variant-specific RT calibration or independent library reconstruction control was authenticated. Independent barcode labels distinguish samples, not original RNA molecules. A future calibrated uncertainty claim needs its model and simultaneous error control stated before access. Neither SD nor the full replicate range is automatically a confidence interval.

PSI is estimated from enrichment, rather than measured by direct inclusion/skip counting for every genotype. The precise calibration code was not opened because it could embed individually measured values. Prefer the authenticated ES contract for an endpoint-relative connectivity question unless a separate metadata/source-code calibration review closes that gate. A common strictly increasing calibration preserves endpoint-relative order/connectivity; genotype-dependent corrections, clipping, tied values, outcome filtering and averaging nonlinear replicate transformations need their actual rules. Do not infer calibration invariance without checking these qualifications.

**Closest prior and distinct estimand.** The originating study already establishes global scaling, proximal interactions and complex-genotype prediction; MoCHI later also uses this dataset. Rediscovering epistasis, context sensitivity or a better scalar prediction is insufficient novelty. A narrower potentially distinct result is an all-endpoint, all-route description or uncertainty-bounded identification of necessary inclusion compromise within the frozen native-reference protein graph. The minimal null must allow arbitrary codon-unary contributions plus a common monotone response, rather than nucleotide additivity alone. A three-state Leu path can itself have a low central state under a codon-unary model, so disconnection alone would not establish intercodon epistasis. Its endpoint is RNA splicing/enrichment within a native exon design, not measured apoptosis, translation, evolution or preservation of the actual isoform protein mixture. A local obstruction must stay restricted to the72 graph and cannot exclude synonymous bypasses outside its11 variable sites.

**Separate material.** The source describes14 genotypes assayed in three cell lines and the older2016 library is a separately generated mutational experiment. Neither is authenticated as a complete72-vertex validation graph. The14-genotype set was selected in the original study, and its labels/measurements are not yet matched here. The18-genotype potential overlap with2016 is only a design bound. Holding back some of nine transfections is conditional same-library replication, not independent exon or independently constructed-library validation. All source calibration/normalization may already use the full library. No independent biological validation is claimed.

### Source2: FAS2016, ranked second

**Qualified local-route reserve, not a full-exon landscape.** It is a native63nt coding exon map with a concrete primary sequence and genuine transfection-level replicates. Supplement Data1 (`ncomms11558-s2.xlsx`) documents all189 single substitutions including replicate ES and read-coverage summaries; Data2 (`ncomms11558-s3.xlsx`) documents double-mutant ES; Data3 (`ncomms11558-s4.xlsx`) documents interaction information. Headers/values were not opened. A future gate must determine whether double-mutant replicate-level observations are actually released or require forbidden raw-data work; the caption alone does not establish that schema.

Sequence-only native translation yields49 potential synonymous single substitutions and1136 potential two-site squares in the declared radius2 design. These are potential designs, not measured complete squares. The published overall95% double coverage cannot be transferred to this selected subset without checking. The shared WT, library and input denominators induce dependence among overlapping squares. An obstruction inside radius2 does not exclude higher-distance bypasses. The25 individually assayed singles offer selected pointwise assay validation, not multistep graph replication. FAS2019 can supply matched design overlap for some variants, but remains the same exon and research programme.

The closest prior already quantifies local robustness and epistasis. A distinct bounded question would certify which same-protein endpoint connections are identified despite unmeasured doubles, preserving all unknowns. Stop if exact sequence labels or replicate observations cannot be matched, or if the intended claim requires full-exon/global routes or another independent exon.

### Source3: WT1/Ke2018, rejected for strict translated-synonymy substitution

The sequence design, processed count paths and independent-transfection Methods are concrete, and10 hexamer contexts provide a useful splicing-method precedent. However, the assay places the target upstream of its intended translation start. It therefore does not solve the strict actual-coding gap by itself. Classifying substitutions by their consequence in native WT1 is possible only as native-reference annotation, with that distinction explicit. Its hexamer contexts are not necessarily same-protein contexts. Output replicate identity also requires reconciliation before any uncertainty analysis: the paper describes two transfections while GEO lists output1-3. EI pooling and pseudocount conventions are documented. Reject as the primary synonymous biological route; do not launch another context benchmark to avoid this limitation.

## Object filter

Revised the initial tempting assumption that the63nt exon can be translated from its first base: it begins at native codon position2. Revised independent-validation expectations: nine output transfections share one library and common input estimate, and a separate paper using the same exon does not supply another independent exon family. Retained the distinction between declared complete design, published aggregate coverage and actual selected-graph measurement completeness, which is still unread.

## Conclusions

1. **Advance only the source/metadata contract for the complete frozen72-vertex FAS2019 native-reference protein graph.** F1-F7 establish a concrete multi-step substrate and traceable processed-replicate contract. This is stronger eligibility than the previously failed cassette/ORF source, but it is not a positive functional discovery or permission to open outcomes.
2. **Do not claim a new splicing epistasis mechanism or independent validation.** The nearest prior already explains global scaling/specific interactions; F8-F9 delimit genuinely separate but incomplete same-exon material. A useful contribution would need route-level partial identification or robustness that survives those established nulls.
3. **Keep FAS2016 conditional and WT1 excluded from strict translated-synonymy replacement.** F8-F11 provide precise bounds and falsifiers, rather than an inferred biological negative.
