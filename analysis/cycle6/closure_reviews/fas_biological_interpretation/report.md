An interval obstruction would require a nonempty threshold interval `(upper bottleneck, minimum endpoint lower]`. Here its absence is an information/criterion result, not a connectedness theorem for an unknown true field. An empirical rectangle can combine extrema from incompatible preparations. It is intentionally a generous set for rejecting the null but may be too broad to certify a particular barrier. These differing logical directions explain why the positive ordinal result and negative barrier result can coexist.

Do not call the nominal 64 raw additive contrasts independent biological degrees of freedom. The latent design has rank 8, but h is unrestricted and latent coefficients are not uniquely identified. On this 72-state graph the nucleotide and codon-unary designs have the same column space, so their agreement is an implementation check rather than biological evidence about within-codon effects.

## Strongest competing explanations

1. **Included-RNA abundance rather than inclusion probability.** Output recovery can reflect transcript abundance/stability per effective template as well as exon inclusion. Julien 2016 itself notes that some enrichment-implied inclusion values above the physical PSI limit might reflect expression effects beyond splicing. This is a source-recognized limitation, not a newly diagnosed source error.
2. **Persistent genotype-dependent RT/PCR recovery.** Constant primer sites and equal amplicon lengths do not guarantee equal reverse transcription, amplification or sequence recovery. A stable bias can survive all preparations and empirical ranges. The preceding measurement review gives a known-answer square with constant true inclusion but variable recovery that rejects the named ordinal null.
3. **Input and effective cellular-template mismatch.** The technical input measures the shared plasmid library, not necessarily each preparation's effective intracellular template representation. Relative WT normalization removes common scales, not arbitrary genotype-dependent discrepancies.
4. **Finite sampling and dependent preprocessing.**27 cross-products share nine outputs, three technical inputs, one library and a sequencing lane. An empirical range is not a confidence interval. Whole-library preparation effects, common denominators and zero-count sampling are not independent per genotype or order.
5. **Incorrect scalar/common-response biology.** Multiple molecular effects or a nonmonotone response can violate the named class without uniquely identifying an intercodon splice-regulatory mechanism. A mathematical exclusion is conditional on the specified single-latent/common-response hypothesis.
6. **Source-format provenance.** The amended parser retains the authenticated first WT record from headerless deposited files. The literal released `header=TRUE` import would consume that record. The separate median-input point is corrected source-formula reconstruction, not authenticated historical numerical reproduction. This does not invalidate the declared primary ratio, but must remain explicit and does not prove the publication wrong.

The fixed full 72 selection, pre-outcome freeze, exact comparisons and retained negative result reduce analytic flexibility. They do not remove the alternatives above. Even simultaneous null rejection and a certified barrier would not prove that the particular barrier requires intercodon effects; in this run there is no envelope-certified barrier at all.
