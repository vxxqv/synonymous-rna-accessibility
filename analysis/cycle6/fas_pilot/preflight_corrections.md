# Corrections preserved before outcome access

All items below were identified using source metadata, proofs or synthetic data. No deposited phenotype table or count file was opened while making these corrections. Five illustrative count rows embedded in the source README were already exposed and are recorded separately.

1. **Edge iterator:** the first bottleneck implementation consumed an iterator while validating edges, then reused it. A synthetic three-vertex example falsely reported a barrier. Both callers now materialize the edge list before reuse. The reviewer retained the original implementation, reproducer and correction receipt. The current list-based production graph was not affected, but the API flaw was real.
2. **Disabled assertions:** Python optimization could skip synthetic assertions. Both production verification scripts now refuse optimized execution. The computational functions use explicit certificate checks.
3. **Equivalent encodings:** an initial suggestion treated nucleotide and codon additive fields as distinct on the selected domain. Exact column-space analysis refuted this. Both spaces have rank eight here. The protocol now uses their equivalence as an implementation check. Earlier source-review wording is superseded by the explicit mathematical correction, not silently presented as a surviving result.
4. **Aligned zero totals:** source-normalization reproduction initially aborted if a source library had no rows in the author's TR1 universe. That would incorrectly prevent the primary partial-information analysis. Undefined source frequencies are now recorded and omitted only in the source median reproduction, while primary missing states remain unknown.
5. **Claim limits:** a global ordinal contradiction and an observed barrier can coexist while the barrier is caused by a single codon gate. The protocol forbids attributing that barrier to interactions solely from coexistence. Persistent RNA recovery differences can also create an ordinal contradiction without altered underlying inclusion.
6. **Thresholds and monotonicity:** obstruction thresholds have an open lower endpoint and closed upper endpoint. Equality gives an empty interval. Only strictly increasing transformations necessarily preserve forced orders. A nondecreasing transformation can collapse them. Neither raw-design rank nor the number of normalization scenarios is an independent biological sample count.

These corrections changed the method before the measurements were examined. They are part of the scientific record and should accompany the frozen pilot.
