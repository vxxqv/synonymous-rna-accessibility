# Focused mathematical review of FAS protocol draft

Reviewed draft: `work/research_cycle6/fas_pilot/protocol_draft_v1.md`, mutable source at time of review. Its source hash is pinned in the handoff receipt. No outcome access.

The primary null and exact dual direction are sound. The interval equivalence extends to finite nonnegative lower bounds and upper bounds that may be +infinity. Unknown [0,+infinity] rows create no forced order under the stated nonnegative endpoint. The P3 unary-gate caveat, fixed72 graph, explicit non-PSI endpoint and descriptive nature of the27 scenarios are appropriate. The following changes were sent to root before freeze:

1. **Exact feasible certificate, not only an exact infeasible one.** Require a rational b with every forced inequality checked exactly, exact tied-score grouping and response values inside every interval. A floating optimizer residual alone cannot certify feasibility. If all rationalized margins are positive, normalization by their exact minimum is valid; otherwise return unresolved unless a verified witness is recovered.
2. **Open/closed obstruction interval.** With weak>= acceptance, the threshold set is (C_U,min(L_s,L_t)]. It is empty at equality or C_U=+infinity. Keep all pair results, including empty intervals, but do not count a zero-length set as a robust obstruction. C_L>=tau certifies connection; C_U<tau certifies separation; the gap is unknown.
3. **Author point estimate aggregation.** Freeze whether the point field is mean_r ES[v,r]/mean_r ES[w,r] or mean_r(ES[v,r]/ES[w,r]); these are different. Nine per-output estimates alone do not specify one point field. This must be settled from the source definition or as an explicit frozen derived summary, before values.
4. **Transformation test.** Order-feasibility invariance needs a strictly increasing transform of interval endpoints, not a merely nondecreasing map that collapses strict orders. Do not expect floating transforms to preserve exact ties automatically. The model's response h itself correctly remains nondecreasing and may plateau.
5. **Input validity and interpretation.** Empty intervals, malformed counts or invalid endpoint mappings are integrity failures, not null rejection. No confidence interpretation follows from replicate extrema. Source count sampling could later support a separate explicitly conditional uncertainty model, but that is not supplied by this pilot.

Useful nonblocking reporting detail: retain the forced-order count and active information alongside finite/unbounded coverage. An all-[0,+infinity] field passes the constant null vacuously; this is a mathematically feasible but scientifically uninformative result, not empirical support for additivity. Unbounded quantities should use documented JSON sentinels rather than nonstandard `Infinity`/NaN tokens or arbitrary finite clipping.

No new competing model or outcome-selected threshold is recommended. Exact counterexamples, a full finite proof and synthetic reference are in the accompanying characterization and receipts.
