# PERSIST endpoint decision before outcomes

Status: proposal for independent review, not a finalized analysis freeze. No new cellular outcome value has been opened.

The exact question is whether the deposited Vienna mean unpaired probability adds predictive value beyond sequence composition and codon usage for the **published cellular degradation coefficient**, when predicting one deposited design source from another within the 37-row fixed NanoLuc protein/context stratum. This is a retrospective prediction test of an experimental RNA persistence proxy. It is not a complete accessibility landscape, a new mechanism, a protein-output test or independent-study validation.

The source R file applies `voom` and `lmFit` to a time design and writes the negative time coefficient. The deposited construct table has a named `degradation_coef_in_cell` column. The visible half-life calculation uses `ln(2)/coefficient` despite the source's log2 processing. Absolute half-life and natural-log decay-rate interpretations are therefore withheld. Exact provenance of the rename into the construct table and the historical software environment remain unverified. The endpoint below is the deposited numerical coefficient in its own reported units, not a newly reconstructed physical rate.

This numerical prediction question does not need a guessed half-life conversion. Every proposed regression has a free intercept, every penalty is fixed or selected using training prediction error only, and MAE ratios compare predictions and outcomes on the same declared scale. Multiplying all responses by a common positive constant multiplies every fitted prediction and error by that constant and leaves model selection and relative improvement unchanged. Translation of all responses is likewise absorbed by intercepts. This limited invariance does not cover genotype-dependent transformations, selective processing, arbitrary monotone transformations or a common conversion that differs between design sources. It does not authenticate an unverified biological measurement pipeline. An independent reviewer should decide whether this narrower, explicit estimand is scientifically defensible before it is adopted.

Proposed immutable membership: main protein hash `dd0e8ca4f9a41c1fdd610ac0e48d953ff55be9483e2067db5e713804931fc148`, barcode-normalized context hash `e682ac5099bf1b6f4beb22f1f9817c89022c0bd31b279975a872546eddf726e9`, 37 longamp-listed rows. Train on the 22 prefix-310 rows; hold all 15 prefix-930 responses until predictions are fixed. Longamp is an author processing flag potentially affected by earlier outcomes, not an outcome-independent sampling frame. Actual experimental barcodes are retained and barcode composition is a nuisance covariate. No pooling with the alternate context or different protein is allowed.

Group development sequences by connected components under CDS Hamming distance at most ten; all identical CDS and near-neighbour designs stay together. Use deterministic leave-one-group-out development prediction to select a ridge penalty from {0.1, 1, 10, 100}. Centre and scale features using each training fold only; constant training features are dropped in that fold. The loss for tuning is total absolute held-fold error divided by development row count. Prefer the larger penalty on a numerical tie within 1e-12. Penalties act on all standardized coefficients except the intercept. No penalty is zero. The final model uses the same preparation fitted on all development rows.

Five fixed comparisons: development median; development mean; a composition ridge with full-RNA mononucleotide and dinucleotide frequencies plus barcode GC; a codon/composition ridge adding sense-CDS codon frequencies to the previous features; one nearest development CDS by Hamming distance, resolving ties by the average response over all nearest ties. No outcome field, solution-stability coefficient or derived expression is a predictor. Primary model: the codon/composition ridge plus the one deposited `AUP.Vienna.FULL` feature. The feature's predicted structural meaning and documented origin must be authenticated before use; no outcomes are used to recompute or select a structure predictor.

Primary endpoint: mean absolute prediction error across all 15 held-out rows, with complete per-row errors for all six models. The operational gain requires at least 10 percent smaller MAE than every declared comparator. This is an effect-size decision on this fixed cohort, not statistical significance. Report RMSE and rank agreement as secondary diagnostics without changing the primary result. Require every selected outcome and predictor to be finite; if a frozen required value is unavailable, stop the complete-cohort comparison and report the coverage gap without selecting a smaller favorable subset. Keep negative and zero coefficients; do not convert them to positive half-lives or discard them.

Predeclare leave-one-validation-row-out MAE gain ranges as influence diagnostics, not confidence intervals. No row, source, threshold, transformation or feature may be changed from observed validation performance. With one study, one protein, related sequences and unresolved preparation identity, no independent-gene bootstrap, biological confidence interval or noise ceiling is justified. The holdout tests a specific source transfer, conditional on the published processing and selected constructs.

Stop if source feature meaning cannot be authenticated, any required row/value is unavailable, a scale discrepancy is known to differ by row/source, the grouped development split is degenerate, or the implementation fails synthetic scale-equivariance and no-leakage checks. If the relative prediction task is rejected in review, preserve that design limitation; do not silently call a metadata audit biological validation.
