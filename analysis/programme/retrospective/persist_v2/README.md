# PERSIST source-transfer pilot

This is a prospective specification for a bounded, selected 37-construct cohort from one reporter study. It tests the incremental predictive value of one newly computed ensemble feature in the source's deposited cellular-coefficient units. It is not a calibrated half-life measurement, measured structure or complete mutational accessibility study.

The original protocol, source hashes, independent proposal review, preflight incident history and synthetic checks are preserved. The candidate freeze authorizes nothing; the separate root freeze authorizes only feature calculation after this exact material is committed. Development outcomes and held-out outcomes require subsequent gates. The historical metadata and engine hashes preserve the original Windows runtime; they are not a claim of cross-platform binary identity.

No target values or observed predictive results are included at this stage. The old deposited AUP feature remains excluded because its provenance could not be established. See protocol.md for all membership, baselines, endpoints, failure rules and dependence limitations. An original unrelated solution-stability exposure is retained in the source audit and does not enter this cohort.
