A single explicitly post-exposure exploratory successor is scientifically defensible only after the separate discrepancy audit establishes a trustworthy operational cohort and excludes substantive parsing or field errors. It cannot be passed off as version1 validation or an exact reproduction of the published cohort.

The ratio column itself is neither the prediction response nor a predictor: the response is log(HL_CNOT3KO), and baseline HL_WT enters the feature basis. If the two half-life fields and the selected cohort remain identical, changing only the diagnostic treatment of HL_FC_LOG2 cannot change any model input. This is a useful separation between a gate and an estimand. It does **not** establish that the half-life estimates are accurate, independently measured or biologically calibrated. A small arithmetic discrepancy can coexist with large unmeasured estimation error.

The count difference likewise is not a null biological result. One missing gene is not automatically negligible: without an error bound, a missing observation can change a mean arbitrarily. More broadly, the unavailable original read/half-life filters can select a nonrepresentative population. The successor must therefore condition its conclusions on its explicitly enumerated deposited cohort and reference eligibility, rather than claim coverage of all expressed genes or all CNOT3 targets.

**Required successor decision, made before fitting:** preserve version1, its failed receipt, all discrepancies and aggregate exposure. Freeze a new version recording exactly which gate interpretation changes and why. Fix the operational5480 ID hash, retain all49 ratio-discrepant rows unless a separately evidenced integrity failure closes the analysis, and preserve the original reference selection, grouping, hash partitions, resource/coverage/count gates, endpoint, six algorithms, sensitivities and success criterion. Do not reselect a cohort or split after inspecting model results. The new report must use the label “post-exposure exploratory, model-held-out prediction of deposited point estimates within this study.” Prior reproduction already used outcomes across the cohort, so neither a later prediction commit nor hiding the evaluation file restores wholly unexamined or closed-book validation. The committed predictions still protect against tuning on the later model error comparison, which is a narrower protection.

**Stop rather than expand** if independent inspection cannot authenticate field meanings or row identity; reveals material unexplained numerical or selection errors; requires choosing among alternative cohorts, corrections or endpoints based on favorable outcomes; or fails the original grouping/coverage/count requirements. Stop also if the intended claim still requires true molecular decay, a direct PTMD contribution, an RNA structural mechanism or independent biological transfer. Those questions need evidence not supplied by this table. In contrast, an unresolved published count or missing variance alone does not logically prohibit the clearly conditioned point-prediction estimand, provided the operational data are authenticated and these limits are accepted explicitly.

The next authorized scientific action is the separately assigned discrepancy audit, not fitting. Its outcome determines whether to close this biological branch with a data-provenance limitation or authorize one narrower exploratory comparison. No extra models, gene selections, trajectory refits or substitute biological branches are proposed here.
