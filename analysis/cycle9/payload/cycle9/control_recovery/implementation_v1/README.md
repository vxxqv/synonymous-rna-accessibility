# K562 three-state calculation

This standard-library CPython 3.12.14 implementation reads only the approved numeric cells and verifies identity/header metadata first. It computes exact stored-decimal rational ratios, all 27 state possibilities, 162 conditional contrast possibilities and 729 completions sharing C.

Protocol and source metadata are pinned by the pre-access freeze. The original source audit remains unchanged and records the earlier closed-numeric stage. An execution authorization records root's later explicit approval. No normalization, pseudocount, fitted model, source FC column or additional state is admitted.

Synthetic command, from any working directory:

    python -B -m unittest discover -s PATH/implementation_v1 -p test_three_states.py -v

The tests read only invented workbook fixtures and the approved protocol text. They never open the biological source workbook.

Run command:

    python -B PATH/implementation_v1/analyze_three_states.py --workbook SOURCE.xlsx --protocol PATH/three_state_protocol.md --contract PATH/three_state_contract.json --freeze PATH/freeze_v1.json --freeze-sha256 FREEZE_SHA --authorization PATH/authorization_v1.json --authorization-sha256 AUTH_SHA --out NEW_OUTPUT_DIRECTORY

All path arguments are explicit; no Git, network, installation or original Windows layout is required by the implementation. The approved external workbook must have its exact pinned hash. Runtime is CPython 3.12.14 with standard-library modules only. The test protocol-text location is relative to this directory.

An existing output path is refused. Optimized Python is refused before inputs or output creation. Guard failures after output creation preserve failure.json, while earlier command/seal errors must be retained by the calling runner. Formula expressions are never executed or used as values: only a present stored numeric cache in an allowlisted cell is admissible.

Result interpretation must use generic M/E/C codes. Completion counts are not biological replicate counts. These finite-source envelopes are not confidence intervals, and source preparation/background limitations remain.
