# COMT A1 amendment: new fixed-runtime source preprocessing

Status: selected pre-outcome route, prepared for independent review. No biological count row, source simulated training row or new phenotype value has been decoded. The former historical-reconstruction blocker is retained in design_blocker.md and source_state_audit.json; neither is rewritten as a successful historical reproduction.

The prospective estimand is defined by protocol_v2.md: held-out-codon-site prediction of negative low-fluorescence-bin enrichment from RNA representation, with a heavy-load comparator. It uses 125 source-ascertained synonymous IDs at 53 codon sites, reports all 113 SNVs, and preserves the source's cross-assay preparation-label ambiguity. It is not an estimate of protein concentration or kinetic compensation.

## New runtime, acquisition and smoke evidence

The installed, task-local runtime is R4.6.1 on Windows. Direct required packages are data.table1.18.6.1, caret7.0-1, randomForest4.7-1.2 and e1071 1.7-17. The candidate binary index required 64 packages totaling 74,719,642 bytes. Exact archive SHA256s, every internal package MD5 verification, actual installed versions and installed-file hashes are retained in runtime/download_manifest.json and runtime/runtime_manifest.json. This does not assert historical version equivalence. The official binary index did not provide an external archive digest, so HTTPS source identity plus recorded SHA and internal MD5 is not misrepresented as independent cryptographic authentication.

The required hamming.distance comes from e1071, not bnstruct. The source's unrelated model imports leaps, gbm, glmnet and mltools are not needed for the RF-only branch. Plotting and additional biological packages in the full notebook are not required for this reconstruction. caret itself imports a substantial dependency closure, which is retained rather than reimplementing its resampling machinery.

source_helpers.R evaluates only the allowlisted original top-level helper assignments. Function bodies and formal arguments are unchanged; their ASTs are checked after evaluation. The caller must reject any model other than rf and must supply NULL for optional mapping/tile arguments. Unused branches remain present in the original function bodies but cannot become an implicit alternate analysis. A full source() of the helpers is not used because it would load unrelated packages.

RNGkind is Mersenne-Twister/Inversion/Rejection, source set.seed(9) calls are preserved, data.table uses one thread, and foreach is explicitly sequential. The source caret allowParallel flag remains at its default TRUE, but the registered backend has exactly one worker. No parallel RNG schedule is assumed. C collation and default treatment/poly contrasts are explicit. These conventions and the installed-file manifest must be checked before any authorized source-row decoding.

The ordinary R Windows binary installer failed on a workspace path exceeding the legacy limit. That failed local library and log were preserved. The identical official ZIPs were then extracted with extended Windows paths into the assigned task-local library, checked, loaded successfully and exercised twice on the same synthetic nested-CV data with identical results. No system/global package files were changed. Initial metadata-parser failures (binary index lacks MD5; ZIP DESCRIPTION uses CRLF; ZIP MD5 uses an asterisk binary marker) occurred before any package execution and were corrected with explicit format handling. An initial synthetic expectation incorrectly treated a full-codon one-change REF/ALT as a source SNP; the source convention was retained and the corrected fixture now tests both representations.

## What remains before outcome authorization

The source algorithm is available and the new runtime is runnable. This resolves the prospective runtime feasibility question, not the historical equivalence question. The selective raw reader, normalized contrast construction, full preparation crosswalk, staged five-fold prediction driver and its source/hash/exposure guards still require implementation and independent synthetic review. The kernel and protocol are ready for review; the biological pipeline is not yet outcome-ready.

Required integration evidence includes poisoned unrequested fields, duplicate/malformed source rows, exact common coverage, complete denominator provenance, MNP collapse, shared references, negative-control absence, nonpositive subtraction, all-zero baselines, missing groups, grouping-map sensitivity, fold isolation and recorded rank/condition/out-of-range diagnostics. No new source-state choice may be made after inspecting prediction targets. A source mapping or runtime discrepancy stops the branch with a recorded reason.

## Explicit alternative, not a silent fallback

The deposited published score tables could support a separately frozen descriptive codon-site prediction audit of the already standardized published scores. That path would avoid reconstructing the raw RF state. It would still inherit source filtering, shared references, global preprocessing and the same 125-ID ascertainment. Exported marginal intervals would not supply calibrated joint predictive uncertainty or cross-assay covariance, and score signs would require source-version authentication before values were opened. Such an audit could compare named predictors of the published proxy scores but could not validate raw assay substitution, protein amount or compensation. It must have its own protocol and cannot be run beside this route and selected because it looks stronger. No score values were opened to assess this option.
