# COMT A1 integration addendum, before outcomes

This adds executable specificity to held protocol_v2.md without rewriting that historical reviewed file. It is not outcome authorization. All current checks use invented values or source metadata only.

The operational heavy-load expansion criterion must pass under EACH of the code and GEO grouping maps. In each map it requires coverage of at least 100 of 125 variants and 40 of 53 codon sites, and a reduction of at least 10% in site-balanced MAE against ALL FOUR baselines: pooled training median, ROI-specific training median, constrained RNA-only linear regression and RNA-only PAVA. A positive improvement below 10% in one map does not pass. Any zero baseline MAE prevents a relative-gain pass. Mid-load performance cannot rescue the primary criterion.

All contrast and error units are natural logarithms, or nats. The source log10 thresholds are used only for source filtering. The 113-SNV subset, at 52 sites, is scored from the same 125-cohort out-of-fold predictions without refitting. The mid sensitivity fits the same joint model with mid load substituted for heavy, using the same five fixed folds and its explicitly reported complete-case population. Both ROI summaries are reported regardless of direction. No grouping map, subset or sensitivity is selected as the preferred result.

selective_contract.json fixes 63 required biological summary members using header and sample metadata only: 11 gDNA, 20 total RNA, 9 low-bin FACS, 10 heavy, 10 mid and 3 negative controls. It records the complete sample identities, GEO accessions and title strings, source-code groups, GEO groups and technical multiplicities. All required four preparation groups exist structurally under both mappings before any numerical missingness is inspected. This is not a claim that all variant measurements will exist. Two simulation summary files and their two truth VCFs are separate source training inputs, not biological validation units. Unused assay bins and libraries are not decoded by the new reader because they cannot affect the required sample-specific denominators or the gDNA-based global filter.

The source background universe is not the target set. Every source-allowed allele at the required ROI positions contributes to its own sample/position denominator after the fixed source RF and frequency rules, whether synonymous or not. The exact TAA/TGA exclusion applies to biological raw records as in the notebook; TAG is not silently added. This exclusion is not applied to the source simulation training records, where the notebook did not apply it. Raw REF/ALT representation is retained. The original per-base MNP records are collapsed by the median for numerical quantities, and WT uses the sum over collapsed variants, not the sum over duplicate per-base rows.

Malformed, negative or nonfinite required count/feature values; duplicate sample/variant/base rows; inconsistent reference bases; a nonunique depth after median collapse; negative WT; lost model-matrix rows or incompatible feature columns stop the run. A failure is preserved without a new subset or imputation workaround. Counts and normalization are validated before fitting. The code does not guess an original historical rejection map.

Target-specific absence remains unavailable. The source's absence-of-negative-control-variant convention remains a zero background subtraction and is explicitly flagged. A nonpositive corrected ratio has no log value. Within an assay preparation group, available technical log values are summarized by their median; an entirely missing group makes that assay unavailable. Independently complete other assays remain visible. Four group summaries are required for a central value or range. Rows do not become independent replicates merely because there are multiple technical preparations.

The complete d, r, f, h and mid preparation vectors and identities are retained. Joint scenario meaning is the Cartesian product of the recorded preparation summaries, with the SAME chosen d reused in R and T and the SAME chosen r reused in R and L. No probability is assigned to that product. Marginal extrema can be conservative and do not describe independent errors. The fitted models use the separately frozen central summaries. No Cartesian scenario is selected to optimize a result.

The numerical normalizer applies the source algebra with rational arithmetic on source counts and their median collapse, then converts the positive corrected ratio to a stored finite float for its natural log. This is a new implementation of the declared formula, not a claim of bitwise equivalence to the historical R floating arithmetic. The source frequency-pass decision is produced by the pinned R runtime so log10-threshold behavior is explicit. The held model kernel uses rational sufficient statistics for its stored finite inputs, not exact biological quantities.

The five phases are selective extraction, new fixed-runtime RF reconstruction, normalization, frozen five-fold prediction and evaluation. Each requires exact file-role hashes, the code freeze and an explicit phase authorization; output directories must be new. Prediction outputs are sealed before evaluation and scoring requires that exact prediction seal in its authorization. This is frozen cross-validation within one ascertained source cohort, not a closed-book external replication. The target field is excluded from the assessment API, and a synthetic target-perturbation test checks same-fold predictions remain unchanged.

Upstream seals must match the current protocol, amendment, integration addendum, contract and code freeze. The RF and normalization stages must reference the same extracted records, and scoring must reference the same normalization as prediction. A consumed output missing from its seal is rejected. A parsing failure records completed members and the currently interrupted member; it does not claim zero exposure for a partially decoded member. No successful-stage seal is written for a failed extraction.

The source helper functions remain unchanged. source_helpers.R loads only the reviewed RF dependency closure and original selected assignments. The adapter uses the source model='rf' branch only and source thresholds, preserves source seeds and retains the source floor-fold remainder behavior. Fewer than ten prepared training rows cannot support the source initial ten-fold split; missing classes or a source fitting error stops preprocessing. There is no parameter tuning against biological assay-prediction results.

Interpretation remains restricted to the named algorithms for these dependent source-normalized proxies. A synthetic control already demonstrates perfect load-model prediction with constant true heavy/RNA load, caused solely by shared RNA measurement error. An observed improvement would not establish compensation, causal load information, physical protein amount, assay equivalence or optimal performance achievable from RNA.
