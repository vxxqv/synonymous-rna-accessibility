## Important technical correction to the access record

The NCBI PMC availability skill's old OA-service call returned HTTP404. The official [PMC OA-service notice](https://pmc.ncbi.nlm.nih.gov/tools/oa-service/) states the service was retired on 25 August 2026; the [current distribution documentation](https://pmc.ncbi.nlm.nih.gov/tools/pmcaws/) says the legacy distribution files were removed that week. Thus the old service failure is not article-specific denial and does not classify the supplements as absent. The skill itself was not edited. Current documented cloud metadata was used instead. A later ordinary requests fetch of the documentation page returned the same generic 403 body as earlier PMC requests; that body is recorded and not retried. The official notice was readable through the browser research tool before that request.

This does not resolve the original media-route 403s. No assertion is made that the exact cause was authentication, expiry, publisher rights or a technical frontend block. The author manuscript's TDM metadata is not permission to manufacture unlisted attachment URLs or to assume every supplement is in the cloud package.
